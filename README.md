# 🎮 ИнтаГадай

Мобильная игра: угадай реальную цену квартиры в Коми (г. Инта) по объявлениям Авито.

- **10 раундов** — в каждом квартира с фотографиями, бегунок цены и кнопка «Оценить».
- **Баллы за точность**: до 100 за раунд (отклонение ≤3% — максимум, дальше −1 балл за каждый процент).
- **Три финала**: 🧐 Жадный студент · 🤝 Адекватный квартирант · 🤑 Транжира — зависит от того, завышал ты цены или занижал.
- После оценки показывается реальная цена, разница и **ссылка на объявление**.

Стиль — ВШЭ (hse.ru), главный цвет `#012D6E`. Всё статичное: никакой серверной части.

## Локальный запуск

Просто открой `index.html` в браузере, либо:

```bash
python -m http.server 8000
# → http://localhost:8000
```

## Публикация на GitHub Pages

1. Создай репозиторий на GitHub (например, `intagaday`).
2. Загрузите **содержимое** этой папки в репозиторий (файлы `index.html`, `style.css`, `app.js`, `data.js`, `README.md` и папку `img/` должны лежать в корне репозитория).
3. В репозитории: **Settings → Pages → Source: `Deploy from a branch` → ветка `main`, папка `/ (root)` → Save**.
4. Через минуту игра будет доступна по адресу `https://<логин>.github.io/intagaday/`.

## Структура

```
intagaday/
├── index.html   # разметка (4 экрана: старт → лот → результат → финал)
├── style.css    # стиль ВШЭ, mobile-first
├── app.js       # логика: раунды, баллы, финалы
├── data.js      # 10 квартир (цены, фото, ссылки на Авито)
├── img/         # сжатые фотографии (≈35 КБ на квартиру)
└── README.md
```

## Обновление данных

Квартиры берутся из CSV (`creative_hse_2026 - квартиры коми.csv`) скриптом
`../scripts/prepare_data.py`: он отбирает 10 лотов с фото, скачивает и сжимает
картинки (JPEG, ширина ≤900 px) и перегенерирует `data.js`.

```bash
python ../scripts/prepare_data.py
```
